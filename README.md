# Portfolio Website

My personal developer portfolio — a single-page site introducing who I am,
my skills, and the projects I've built.

**🔗 Live site:** https://faisalhasanmahin.github.io

## Built with

Prototyped and designed using **[Claude Design](https://claude.ai)**, then
customized, hand-tuned, and deployed by me — the layout, content, styling, and
interactions were tailored to make it my own.

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Markup | HTML5 (single page) |
| Styling | Custom CSS (no framework) + Google Fonts (Space Grotesk, Archivo, Poppins, JetBrains Mono) |
| Interactions | Vanilla JavaScript — custom cursor, scroll progress bar, canvas particle fields, animated menu, mailto contact form |
| Rendering | Claude Design runtime (client-side React hydration) |
| Hosting | GitHub Pages |

## Features

- Responsive single-page layout with smooth-scroll navigation
- Animated hero with canvas particle field and a custom cursor
- Skills, Projects, and Contact sections
- Downloadable résumé
- Contact form that composes an email via the visitor's mail client

## Deployment

Hosted on GitHub Pages from the `main` branch (root folder). Every push to
`main` updates the live site.
